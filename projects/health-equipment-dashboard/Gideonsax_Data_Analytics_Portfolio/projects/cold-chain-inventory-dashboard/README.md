# Cold Chain Inventory Dashboard

## Project overview
This case study documents a Power BI dashboard designed to present cold-chain equipment (CCE) inventory indicators and support review of equipment status across administrative areas.

## Questions the dashboard is designed to support
- How is recorded CCE inventory distributed across states?
- How do functional and non-functional equipment counts compare?
- How does equipment status vary by equipment type?
- Which indicators may require follow-up or data-quality review?

## Tools
- Microsoft Power BI
- Microsoft Excel

## Dashboard features 
- KPI cards for total CCE equipment, functional equipment, non-functional equipment, and not-installed equipment
- State coverage indicator and total-state count
- Geographic distribution map
- State-level comparison table
- Top-10 state visual
- Equipment-type and functionality-status breakdown


## Analytical approach
1. Confirm the data grain.
2. Check status categories, blanks, duplicate records, and inconsistent labels.
3. Verify KPI measures and denominators.
4. Compare status distributions by state and equipment type.
5. Record findings only where supported by the underlying data.
6. Link recommendations to validated findings.

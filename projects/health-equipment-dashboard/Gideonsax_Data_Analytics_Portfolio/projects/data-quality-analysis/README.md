# Data Quality and Validation Analysis

**Status:** Planned project

## Objective
Demonstrate a transparent workflow for checking and improving tabular data quality for programme monitoring, using synthetic or explicitly approved data.

## Planned checks
- Missing and blank values
- Duplicate records
- Inconsistent category labels
- Invalid data types and date formats
- Standardisation of administrative names
- Validation rules and exception reporting

## Tools
- Microsoft Excel
- Power Query, if used

## Planned deliverables
- Synthetic sample dataset
- Data-quality issue log
- Before-and-after summary
- Reusable validation checklist
- Short report with limitations and recommendations

No confidential or identifiable source data will be published.

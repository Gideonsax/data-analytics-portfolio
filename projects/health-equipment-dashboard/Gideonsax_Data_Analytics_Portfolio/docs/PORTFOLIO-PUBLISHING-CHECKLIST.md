# Portfolio Publishing Checklist

- [ ] Review every file before committing.
- [ ] Do not publish original `.pbix` files unless expressly authorised.
- [ ] Do not publish confidential spreadsheets, facility identifiers, beneficiary information, credentials, or internal report links.
- [ ] Use only approved screenshots or synthetic examples.
- [ ] Verify every number, unit, date, and calculation.
- [ ] Clearly label preliminary screenshot observations.
- [ ] Add a LinkedIn URL and professional contact email to the main README.
- [ ] Replace placeholder text only with accurate information.
